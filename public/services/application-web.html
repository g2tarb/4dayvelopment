Quel type d'application pouvez-vous lancer ?

4dayvelopment développe trois types d'applications web, prêtes à accueillir vos premiers utilisateurs :

  • un MVP, pour tester une idée de produit auprès de vrais utilisateurs ;
  • un outil métier, pour remplacer un fichier ou un processus interne ;
  • une plateforme, qui met en relation des utilisateurs ou des clients.

Chaque application est installable (PWA) : elle s'ajoute à l'écran d'accueil d'un téléphone ou d'un ordinateur depuis le navigateur, sans passer par les stores.

Questions fréquentes

Qu'est-ce qu'une PWA ?

Une application web progressive (PWA) fonctionne dans le navigateur et peut s'installer sur l'écran d'accueil d'un téléphone ou d'un ordinateur, sans passer par l'App Store ni Google Play.
